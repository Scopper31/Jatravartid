## Ключевые функциональные компоненты

- **Настройка и конфигурация API**
  - **API Setup and Configuration**: Скрипт настраивает API Google Generative AI, используя API-ключ, и выбирает модель (gemini-1.5-flash) для выполнения задач на базе ИИ.
  
- **Управление пакетами**
  - **import_list_of_packages**: Устанавливает необходимые пакеты Python с помощью pip.
  
- **Управление проектной папкой**
  - **file_work**: Создает директорию для проекта и инициализирует файл журнала для отслеживания прогресса.
  - **create_file**: Записывает код в файлы внутри проектной директории.
  - **generate_alias**: Генерирует псевдоним или короткое имя для папки проекта с использованием ИИ.
  
- **Отладка с использованием ИИ**
  - **test_mistakes_with_gpt**: Использует ИИ для обзора и выявления потенциальных ошибок в одном Python файле.
  - **multyfile_test_mistakes_with_gpt**: Аналогично предыдущему, но для проектов с несколькими файлами, решает ошибки в файлах и их взаимосвязях.
  
- **Логирование**
  - **add_to_log**: Записывает ответы ИИ и другую важную информацию в файл журнала внутри проектной директории.
  
- **Извлечение блоков кода**
  - **extract_blocks**: Извлекает конкретные блоки текста из строки с использованием начальных и конечных маркеров, полезно для изоляции блоков кода или разделов текста.
  
- **Анализ кода (Linting)**
  - **run_pylint_with_ultimate_flags**: Запускает pylint на Python файлах проекта с использованием набора флагов для обеспечения стандартов кодирования и выявления проблем.
  
- **Автоматизация рабочего процесса разработки**
  - **develop**: Использует ИИ для итеративного улучшения и усовершенствования Python проекта на основе поставленной задачи, генерирует и исправляет код в нескольких файлах.
  
- **Управление задачами**
  - **solve_task**: Управляет всем процессом разработки, начиная с разбивки задач и заканчивая интеграцией и отладкой кода, предоставленного несколькими разработчиками (используя ИИ для имитации командной среды).

## Структура проекта

Проект включает несколько ключевых модулей:

- **Модуль Генерации Задач**: Позволяет разбивать задачу на части и распределять их между несколькими разработчиками.
- **Модуль Генерации Кода**: Генерация кода на основе заданных технических требований.
- **Модуль Тестирования и Отладки**: Автоматическое тестирование и поиск ошибок в сгенерированном коде.
- **Модуль Интеграции и Сборки**: Интеграция различных частей кода в единый проект, исправление ошибок и проверка на соответствие техническому заданию.

## Используемые технологии

- **Python 3.x** — основной язык программирования.
- **Google Generative AI** — для генерации и анализа кода.
- **Pylint** — для проверки кода на соответствие PEP 8 и поиска ошибок.
